# AAINAA Designs — Luxury D2C Flagship Storefront

A bespoke, high-converting luxury e-commerce showroom built for **AAINAA Designs** (founded by Jaleena Shan, Kakkanad, Kochi, Kerala).

---

## 🌟 Architecture & Features

- **Anti-AI Slop Aesthetic:** Handcrafted editorial layout using `Cormorant Garamond` (editorial serif) and `Plus Jakarta Sans` (minimal geometric sans).
- **Artisan Color Palette:** Warm Alabaster Linen (`#fbfaf8`), Deep Obsidian (`#141716`), and Champagne Warm Gold (`#c5a059`).
- **Real Verified Products:** 20 flagship silhouettes loaded directly from AAINAA's Kerala studio catalog with actual pricing, fabric provenance, and high-res photography.
- **Interactive Shopping Bag Drawer:** Slide-out drawer with live subtotal calculation, free shipping progress bar, and quantity modifiers.
- **1-Click WhatsApp VIP Checkout Bridge:** Automatically formats line items, sizes, quantities, and totals into a pre-filled WhatsApp message sent directly to Jaleena's studio line (`+91 6282719098`).
- **Quick View Modal:** Fast silhouette preview with instant size selection.
- **Bespoke Made-to-Measure Module:** Direct custom-sizing inquiry builder for tailored cuts with zero sizing stigma.
- **Zero Heavy Dependencies:** Pure, lightning-fast static architecture that loads in < 0.5s, ready for 1-click Vercel or Netlify hosting.

## 🚀 How to Run Locally

You can preview the store immediately by opening `index.html` in any browser, or serving it with Python / Node:

```powershell
# Quick Python HTTP Server
python -m http.server 3000 --directory "C:\Users\mobpi\.gemini\antigravity\scratch\aainaa-luxury-store"
```

Open `http://localhost:3000` in your browser.
